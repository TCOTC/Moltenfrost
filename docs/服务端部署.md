# 服务端部署（腾讯云 CVM）

面向"把工程源码部署到一台按量计费的云服务器，供跨网双人调试"。

结论与坑在这里，`AGENTS.md` 只留一行指路。

## 为什么是源码部署而不是导出产物

服务器上跑的是**同一份工程源码**，不是导出的产物。两个理由：

- 改一行代码只要重新部署一次，不必重新导出与上传几十兆的产物；
- 权威服务端要执行物理与机关判定，若另用一套实现就要重写刚体动力学与碰撞求解，
  而两套实现必然分叉（设计文档 4.5）。用同一份工程是唯一能保证两边一致的做法。

服务器**不需要**导出模板，也不需要编辑器——只要 Godot 的 Linux 二进制与仓库。

## 部署

```powershell
# 完整部署（首次或重建机器）
node tools/deploy-server.mjs --host 106.52.118.93 `
  --advertise moltenfrost-server.mytemos.com --enable-service

# 只更新代码（日常改了代码之后）
node tools/deploy-server.mjs --host 106.52.118.93 `
  --advertise moltenfrost-server.mytemos.com --skip-godot
```

两个脚本分工明确，都可单独执行：

| 文件 | 在哪里跑 | 做什么 |
| --- | --- | --- |
| `tools/deploy-server.mjs` | 本机 | 准备 Godot 压缩包、打 bundle、上传、远程调下一个 |
| `tools/server-setup.sh` | 服务器 | 装依赖、装 Godot、部署仓库、`--import`、自检、装 systemd |

`deploy-server.mjs` 在**工作区有未提交改动时会直接失败**。这不是多余的谨慎：
bundle 只包含已提交的 `main`，未提交的代码不会随它过去，于是服务器上跑旧代码、
新参数被静默忽略，表现为"参数传了但没生效"，很难联想到是部署内容的问题。
（2026-09-26 就是这么白查了一轮。）

## 两台开发机与服务器必须同一个 commit

`AGENTS.md` 已有这条约束，部署时尤其要注意：产物与源码是两份快照，
分叉之后"本机能跑、服务器上不行"会变成常态。`deploy-server.mjs` 会打印实际部署的 commit，
服务器上也能 `git -C ~/moltenfrost log -1` 复核。

## 服务器访问不了 GitHub

实测（2026-09-26，腾讯云广州）：

| 检查 | 结果 |
| --- | --- |
| `getent hosts github.com` | 正常，解析到 `20.205.243.166` |
| `curl https://github.com` | **exit 28，连接超时** |
| release asset、`objects.githubusercontent.com` | 同样超时 |
| 六个常见 GitHub 加速代理 | **全部 `http=000`** |
| 清华 TUNA 镜像 | 不通 |
| 只有 `cnb.cool` 通 | 3.4 MB/s，但它不托管 Godot |

**因此不能指望在服务器上 `git clone` 或 `curl` 下载任何东西。** Godot 二进制与仓库
都必须从本机上传（`git bundle` + `scp`）。

本机侧的下载也不稳：同一链接实测先 550 KB/s、再降到 22 KB/s、最后完全超时；
`ghfast.top` 代理可用但会劣化到 8.5 KB/s。**74 MiB 的 Godot 二进制在国内没有可靠途径。**

推论：**下到手的 Godot 压缩包要留着。** 它缓存在 `build/server/`，已加进 `.gitignore`
（不入库，但也不要清理）。

## 依赖库：`ldd` 有盲区

Godot 的 Linux 二进制是动态链接的，即使 `--headless` 也要在加载阶段解析符号；
Ubuntu Server 最小安装不带这些库。装的是**运行时包**（`libx11-6`），不是编译用的 `-dev` 包。

**包名随发行版变动**（`libasound2` 在 24.04 起改名 `libasound2t64`），所以不要照抄网上的
列表，而要复核。复核分两步，**缺一不可**：

| 手段 | 覆盖 | 说明 |
| --- | --- | --- |
| `ldd /opt/godot/godot` 看 `not found` | 直接链接的库 | 报得准 |
| 跑一次 `godot --version` 搜 `cannot open shared object file` | **dlopen 加载的库** | `ldd` 看不到 |

实测 `libfontconfig.so.1` 属于第二类：`ldd` 报告"全部解析成功"，而实际启动会打印
`libfontconfig.so.1: cannot open shared object file`。它**不会导致启动失败**（只影响字体渲染，
无头服务端用不上），因此很容易被当成噪声忽略——但每次启动都多一行疑似报错，会干扰以后的排查。
`server-setup.sh` 两步都做，任一步失败即中止。

## 服务端配置

systemd 用 **template unit**（`moltenfrost@.service`），`%i` 是端口：

```bash
sudo systemctl enable --now moltenfrost@27015   # 一个房间
sudo systemctl enable --now moltenfrost@27016   # 第二个房间
journalctl -u moltenfrost@27015 -f              # 看日志
```

这么设计是因为设计文档 4.5 定的并发上限等于进程数：一个无头进程服务一场对局，
多开几场就是多启几个实例。按 BF1.MEDIUM2 的余量（25 万 pps、实际用量 240 pps），
一台机器同时跑 2～3 个对局毫无压力。

`--advertise` 写死在单元里而不是做成逐实例参数：同一台机器上多开时每个端口对外的
地址是同一个域名，逐实例传反而容易漏。

## `--advertise` 为什么必需

云服务器上 `IP.get_local_addresses()` 只有 VPC 私网地址（本例 `172.16.0.17`），
**公网地址是 NAT 映射的，网卡上根本不存在**。于是 HUD 与日志里"对方加入时填"那一行
会指向一个别人连不上的地址。`--advertise <域名或地址>` 就是用来覆盖它的：

```text
[lan] 已在 UDP 27016 广播房间「ubuntu 的房间」（游戏端口 27015）
[lan] 对方加入时填：moltenfrost-server.mytemos.com:27015
```

## 域名与 DNS

Cloudflare 上一条 A 记录指向服务器公网 IP，**Proxy status 必须是 DNS only（灰色云朵）**。
橙色云朵的代理解析只转发 HTTP/HTTPS 的特定 TCP 端口，**完全不转发 UDP**，
而 ENet 走 UDP，开了代理必然连不上，且现象是"连接超时"，很难联想到 DNS。

用域名而不是 IP 的另一个好处：`关机不收费`模式会释放公网 IP，重启后拿到新的，
而域名不变。

## 安全组

**购买页那个「安装安全组规则」开关默认关闭，不打开的话勾选框全部无效。**
实测结果是入站规则为空，于是 ICMP 与 TCP 22 同时超时，看起来像实例没起来。
VNC 能进即说明服务器正常，问题纯在安全组。

必须在「网络与安全 → 安全组 → 入站规则」手动加：

| 来源 | 协议端口 | 用途 |
| --- | --- | --- |
| `0.0.0.0/0` | `TCP:22` | SSH |
| `0.0.0.0/0` | `UDP:27015` | 游戏 |
| `0.0.0.0/0` | `ICMP` | 便于用 ping 判断可达性 |

判据：**TCP 超时（而非拒绝）= 包被静默丢弃 = 安全组没放行**。

注意 `ping` 通不代表 UDP 通，两者在安全组里是分开的条目。

## 日常操作

```powershell
# 开机（关机不收费之后公网 IP 会变，记得更新 Cloudflare 的 A 记录）
# 控制台 → 实例 → 开机

# 改完代码部署
node tools/deploy-server.mjs --host <地址> --advertise <域名> --skip-godot

# 停止省钱：控制台关机时**要选「关机不收费」**（默认可能是继续收费）
# 对应 API 参数是 STOP_CHARGING，默认值是 KEEP_CHARGING
```

## 成本

按量计费 + 公网按流量：

| 项目 | 单价 | 说明 |
| --- | --- | --- |
| 实例 BF1.MEDIUM2 | 0.058 元/小时 | 2 核 2G |
| 云盘 高性能 20 GiB | 0.0009 元/GiB/小时 | **关机期间照收**，约 13 元/月 |
| 公网流量 | 0.80 元/GB | 只收出网；两个玩家约 10 KB/s，可忽略 |

关机不收费**不包含云盘**，所以云盘是月度底价。实测每次调试 3 小时约 0.17 元。

选择云盘类型时按最便宜的选（高性能云硬盘）：性能上你的负载是"启动时顺序读 60 MB"，
之后几乎不碰磁盘，任何盘型都过剩；而它是关机期间唯一持续计费的项目。
